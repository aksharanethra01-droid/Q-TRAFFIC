# Q-TRAFFIC UI prototype

This is a complete frontend-only demonstration of the Q-TRAFFIC digital twin described in the brief.

## Run

Open `index.html` directly in a modern browser. No installation, backend, API, database, authentication service, or external network connection is required.

## Included flow

- Cinematic intro scene
- Demo login and role selection
- Coimbatore location selector
- Procedural perspective traffic simulation with vehicles, signals, buildings, road markings, street lights, and a simulated ambulance
- Traffic prediction, metrics, queues, comparison charts, environmental panel, camera feeds, and audit UI
- Visual QUBO / QAOA optimization sequence
- Emergency response and green-corridor sequence
- Scenario controls: normal, peak hour, accident, festival, road closure, and emergency
- Local browser SpeechSynthesis welcome voice
- Midnight-indigo / aurora colour theme
- Welcome voice starts automatically after entering the dashboard; there are no mute, unmute, or replay controls

All displayed values and behaviors are local mock/demo state. The project intentionally contains no backend, API calls, real quantum computation, blockchain implementation, or external service integration.
